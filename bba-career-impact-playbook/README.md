# The BBA Career & Impact Playbook

A practical, reusable field guide for BBA students, presented in Mohammad Hammad Faridi's name.

**Live site:** https://varmad07.github.io/resume/bba-career-impact-playbook/

## Scope

The playbook covers career tracks, academic planning, skill building, portfolio projects, internships, scholarship and funding routes, graduate-study decisions, and optional international-development pathways.

## Editorial note

This is a reference guide rather than a personal achievement record. Examples are learning exercises unless explicitly stated otherwise. Opportunity rules and funding information should always be checked against the linked official sources before applying.
